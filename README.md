# Система проката автомобилей

Учебное HTML + Python веб-приложение на Flask с базой данных SQLite.

## Возможности
- Каталог автомобилей (марка, модель, госномер, VIN, год, КПП, топливо, пробег) и классов авто.
- Учёт клиентов.
- Создание и управление арендой автомобилей.
- Учёт технического обслуживания автомобилей.
- CRUD для пяти сущностей: классы авто, автомобили, клиенты (с водительским удостоверением), аренды, обслуживание.
- Поиск по спискам, проверка обязательных полей, проверка отрицательных цен, диапазона дат, года выпуска и уникальности госномера.
- Автоматические тесты Pytest.123123
- Пример Jenkins Pipeline.

## Запуск в Windows PowerShell
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000

## Запуск в Linux/macOS
```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 app.py
```

Откройте http://127.0.0.1:5000

## Тесты
```bash
python -m pytest -v
```

Тесты используют временную SQLite-базу и не изменяют рабочую базу приложения.

## База данных
По умолчанию файл создаётся в `instance/rental.db`. Таблицы создаются автоматически при импорте приложения. Чтобы использовать другой путь, задайте переменную окружения `DATABASE`.

## CRUD-операции
Для каждой из пяти сущностей реализованы:
- Create: `POST /<entity>/new`
- Read: `GET /<entity>` (список)
- Update: `POST /<entity>/<id>/edit`
- Delete: `POST /<entity>/<id>/delete`

Сущности: `cars`, `categories`, `customers`, `rentals`, `maintenance`. Таким образом, реализовано не менее 20 базовых CRUD-действий. Дополнительно доступны формы редактирования по GET и просмотр главной панели.

## Jenkins
`Jenkinsfile` в корне содержит стадии Checkout, Check Python, Install dependencies и Automated tests.
В примере используется Linux-агент Jenkins (`sh`). Для Windows-агента замените `sh` на `bat`. Для запуска по push настройте GitHub webhook на доступный адрес Jenkins и включите соответствующий триггер в Job.

## Важно для учебной демонстрации
- Используйте только тестовые данные.
- Не размещайте секреты и токены в репозитории.
- Пример Pipeline реализует CI (получение кода и тестирование). Реальное CD-развёртывание необходимо добавить под конкретную среду.
- Приложение предназначено для учебной работы и не является готовой production-системой: перед реальным использованием нужны аутентификация, авторизация, CSRF-защита, резервное копирование и дополнительные проверки.

## Тестовые данные
В архиве уже лежит заполненная база `instance/rental.db`. Чтобы пересоздать данные (6 классов, по 20 автомобилей, клиентов, аренд и записей обслуживания), выполните `python seed.py`. Скрипт очищает таблицы перед заполнением.
